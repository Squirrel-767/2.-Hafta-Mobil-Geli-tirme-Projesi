2. Hafta Alışveriş Uygulaması Demosu (Flutter)

Bu proje, Flutter kullanılarak geliştirilmiş dinamik ve modern bir e-ticaret mobil katalog uygulamasıdır.

---

Proje Kazanımları:

- Giriş ve Kayıt Ekranı Oluşturma
- Grid Ekranlı Ana Sayfa Oluşturma
- Arama Sistemi
- Sepet Sistemi
- JSON dosyası okuma
- API'den veri çekme

## Kurulum Rehberi

Projeyi kendi bilgisayarınızda çalıştırmak için terminalde sırasıyla şu adımları izleyebilirsiniz:

```bash
# 1. Projeyi Klonlayın veya İndirin:
git clone https://github.com/Squirrel-767/2.-Hafta-Mobil-Geli-tirme-Projesi.git

# 2. Proje dizinine gidin:
cd 2.-Hafta-Mobil-Geli-tirme-Projesi

# 3. Gerekli bağımlılıkları yükleyin:
flutter pub get

# 4. Uygulamayı çalıştırın:
flutter run
